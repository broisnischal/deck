Changelog

What's new in each version of Deck.

0.1.0 · October 2026 · first preview

The first version of Deck: one native Mac window for terminals, a browser and coding agents.

Chats

  • Chat with Claude Code, Codex, Gemini CLI, Grok and OpenCode; switch agents mid-thread.
  • A live work log with every command, read and edit, and a list of changed files after each turn.
  • Approvals and questions above the message box; access modes per thread.
  • Undo to Here and Edit from Here: go back to before any message, files and chat.
  • Prompt rewriting, smooth streaming, select and copy anything.
  • Failed turns retry by themselves; usage limits wait for their reset.

Tasks

  • Tasks on their own branch and checkout, with Preview, review, Merge, Open PR and Discard.
  • Agents can hand out tasks and hear back when each one finishes.

Terminals and the browser

  • A fast terminal with images and files pasted as paths, soft diff colours, and search.
  • A browser with suggestions, a new tab page of your sites and running servers, find, downloads and the Web Inspector.
  • Deck can be your default terminal for scripts and ssh: links.

The workspace

  • ⌘K command palette, snippets with ⌘; and ;keywords, searchable settings and your own shortcuts.
  • Session restore, five themes, Lock with Touch ID, notifications when an agent needs you.
  • The deck command and built-in tools for agents.
