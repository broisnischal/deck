Getting started

Up and running in a minute

  1. Move it to ApplicationsOpen the download and drag Deck into your Applications folder.
  2. Open Deck and sign inContinue with Google in your browser; Deck picks up from there, and your 14 free days start.
  3. Pick your agentsDeck finds the agent CLIs you have, like Claude Code or Codex. Install one if you have none.
  4. Start a chatPress ⇧⌘N, say what you want, and watch it work.
Requirements

What you need

  • A Mac with macOS 13 Ventura or later, Apple silicon or Intel
  • At least one coding agent CLI, signed in: Claude Code, Codex, Gemini CLI, Grok, OpenCode, Cursor Agent, Amp or Aider
  • Git, for tasks and undo (it comes with Apple's command line tools)

Good to know

  • Deck adds a deck command for its own terminals, which agents use to open terminals and pages for you.
  • For notifications from Claude Code running in a terminal, set "preferredNotifChannel": "iterm2" in ~/.claude/settings.json.
  • Deck updates itself: it says so in the title bar when a new version is ready.
